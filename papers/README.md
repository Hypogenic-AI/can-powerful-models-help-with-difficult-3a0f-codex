# Downloaded Papers

1. **MLE-bench: Evaluating Machine Learning Agents on Machine Learning Engineering** — Chan et al., ICLR 2025, arXiv:2410.07095. `2410.07095_mle_bench.pdf`. Seventy-five Kaggle tasks, human leaderboard baselines, medal rate, resource scaling, and contamination analysis.
2. **PaperBench: Evaluating AI's Ability to Replicate AI Research** — Starace et al., 2025, arXiv:2504.01848. `2504.01848_paperbench.pdf`. Twenty paper-replication tasks and 8,316 author-backed rubric items; key capability benchmark.
3. **RE-Bench: Evaluating frontier AI R&D capabilities of language model agents against human experts** — Wijk et al., 2024, arXiv:2411.15114. `2411.15114_re_bench.pdf`. Seven realistic environments with time-budgeted human comparisons and exploit analysis.
4. **FrontierMath** — Glazer et al., 2024, arXiv:2411.04872. `2411.04872_frontiermath.pdf`. Expert-written, contamination-resistant advanced mathematics with automated verification.
5. **Accelerating Clinical Evidence Synthesis with Large Language Models (TrialMind)** — Wang et al., 2024, arXiv:2406.17755. `2406.17755_trialmind.pdf`. Search, screening, extraction, and human-AI evidence-synthesis evaluation.
6. **MLAgentBench** — Huang et al., 2023, arXiv:2310.03302. `2310.03302_mlagentbench.pdf`. Thirteen ML experimentation tasks and an interpretable ReAct baseline.
7. **The AI Scientist** — Lu et al., 2024, arXiv:2408.06292. `2408.06292_ai_scientist.pdf`. End-to-end idea, code, experiment, paper, and review pipeline; useful chiefly as a systems baseline.
8. **SWE-bench** — Jimenez et al., ICLR 2024, arXiv:2310.06770. `2310.06770_swe_bench.pdf`. Executable real-repository issue resolution benchmark.
9. **Sabotage Evaluations for Frontier Models** — Benton et al., 2024. `anthropic_2024_sabotage_evaluations.pdf`. Threat models and mitigation-aware evaluations for code sabotage, sandbagging, human decisions, and oversight subversion.

All nine PDFs were validated with `pypdf`. PaperBench, RE-Bench, and Sabotage Evaluations were split into 8-page chunks under `papers/pages/` and every chunk was processed for detailed review.
